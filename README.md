# sunfmin/homebrew-tap

Homebrew tap for [sunfmin](https://github.com/sunfmin)'s tools.

## Install

```sh
brew install sunfmin/tap/md2json
```

Or tap first, then install by short name:

```sh
brew tap sunfmin/tap
brew install md2json
```

## Formulae

| Formula | Description |
| --- | --- |
| [`afkconvoy`](Formula/afkconvoy.rb) | Fleet of AFK coding agents that works a GitHub backlog. Source: [sunfmin/afkconvoy](https://github.com/sunfmin/afkconvoy). |
| [`claude-stall-guard`](Formula/claude-stall-guard.rb) | Stall watchdog for Claude Code: turn interactive-prompt hangs into fast failures. Source: [sunfmin/claude-stall-guard](https://github.com/sunfmin/claude-stall-guard). |
| [`flux-toolchain`](Formula/flux-toolchain.rb) | Flux refinement type checker for Rust, with liquid-fixpoint and z3; the newest, rebuilt daily. Source: [sunfmin/flux-toolchain](https://github.com/sunfmin/flux-toolchain). |
| [`md2json`](Formula/md2json.rb) | Markdown to JSON CLI (CommonMark + GFM via goldmark, mdast-style envelope). Source: [sunfmin/md2json](https://github.com/sunfmin/md2json). |
